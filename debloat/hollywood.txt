# Hollywood: FFALCON 75" U65 Google TV (FF75U65), 192.168.0.4, wired.
# TCL G10 board, product G10_4K_GB_NF_32BIT, build STT2.230203.001 (AS12), Android 12 (SDK 31),
# Realtek rtd6748, armeabi-v7a only, 1.8 GB RAM. Read from the TV on 2026-10-22 (baseline/2026-10-22/).
#
# Same product and build as cleanyourtv's examples/tcl-g10-google-tv (confirmed there on a TCL 55P6K),
# which is where this list started. Differences from that list are noted inline.
#
# Phase A only: nothing here touches Home. The packages that hand Home to our launcher live in
# hollywood-launcher.txt and go only after apps/tv is installed and opened by hand.
#
# Apply:   tools/debloat.sh apply debloat/hollywood.txt
# Undo:    tools/debloat.sh restore debloat/hollywood.txt
# Check:   tools/debloat.sh status debloat/hollywood.txt
# Everything is DISABLED (pm disable-user), not uninstalled. Comment out a line to keep it.
#
# Factory state: nothing was disabled (`pm list packages -d` empty). Unlike the US G10 unit,
# Samba TV ACR, ttvs and logkit all ship ENABLED here.
#
# NEVER DISABLE (the TV depends on them, or we do):
#   com.tcl.tv, com.tcl.tvinput          live TV and every HDMI input
#   com.tcl.suspension                   the Input picker (handles com.android.tv.action.VIEW_INPUTS)
#   com.tcl.dashboard, com.tcl.systemserver, com.tcl.providers.config, com.tcl.initsetup,
#   com.tcl.useragreement, com.tcl.factory.view, com.tvos, com.realtek.*
#   com.tcl.autopair                     Bluetooth remote pairing
#   com.tcl.globalkeyoverlay             the remote's Netflix/Prime/YouTube/Disney+ hotkeys
#   com.tcl.inputmethod.international    the active keyboard (com.google.android.inputmethod.latin is the fallback)
#   com.tcl.hearaid                      sound and accessibility settings
#   com.tcl.airplay2, com.realtek.airplay2   AirPlay, which is how the house casts (iPhones)
#   com.google.android.tv.remote.service Remote v2 (ports 6466/6467): the iOS app depends on it.
#                                        cleanyourtv's G10 list disables it; we must not.
#   com.android.tv.settings, com.android.vending, com.google.android.gms, com.google.android.gsf,
#   com.google.android.webview, com.android.providers.tv
#
# Wait at least 10 seconds after applying before any reboot: PackageManager writes the new states
# to disk after a short delay, and a reboot inside that window brings packages back enabled.
